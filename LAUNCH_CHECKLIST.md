# SpaceBox — Sign-off Checklist Before Public Launch

- [ ] Domain selected, controlled by SpaceBox, DNS + HTTPS working.
- [ ] Legal entity name, company address (if published), contact phone, mailbox and founder profile verified.
- [ ] Rights/licenses and approvals confirmed for every reference/stock/photo/video asset.
- [ ] No watermarked or third-party imagery used without authorization; examples labeled accurately.
- [ ] No invented projects, certification claims, client reviews or revenue promises.
- [ ] Privacy notice/consent and record-retention procedure approved by legal counsel.
- [ ] Production Postgres, encrypted backups and restore rehearsal completed.
- [ ] Uploaded project media placed on **persistent** storage and backed up; disk capacity monitored.
- [ ] Unique administrator accounts created; owner/editor/sales roles checked; strong individual passwords.
- [ ] APP_SECRET set and kept secret; SITE_URL and ALLOWED_HOSTS accurate; secure cookies confirmed.
- [ ] Enquiries tested end-to-end with actual SMTP delivery; failed-notification fallback monitored.
- [ ] CAPTCHA or WAF/bot rules and host-level request limits configured for public exposure.
- [ ] Content-security, server patching, uptime/exception monitoring and incident owner assigned.
- [ ] Real project uploaded as draft; inaccessible anonymously; then published; public image verified.
- [ ] All key customer pages validated on real iPhone, Android, desktop and tablet.
- [ ] Google Search Console, sitemap, canonical metadata and analytics consent (if applicable) validated.
- [ ] Stakeholders approve the live launch and rollback plan.
